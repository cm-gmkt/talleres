Rutas laterales

No oportunidad: para quien hoy no puede avanzar o no califica.

Regla

Una etapa debe cambiar una acción, una información necesaria o una condición de avance. Evitar crear etapas solo para “ordenar”.

Validación Messenger → oportunidad

Resultado técnico: HighLevel crea un contacto cuando alguien escribe por Facebook Messenger; su documentación también permite disparar workflows desde mensajes/replies de Facebook y usar una acción de Create/Update Opportunity. Por lo tanto, el flujo es técnicamente viable.

La implementación debe probarse en la subcuenta real para decidir el punto exacto: A) crear oportunidad desde el primer mensaje, o B) esperar a que exista teléfono y crearla entonces. Para ARQCOES recomendamos probar primero B si la intención es que el pipeline contenga únicamente prospectos con dato de contacto útil; si Ulises quiere visibilidad total desde el primer DM, puede usarse A.

No mezclar contacto con oportunidad: el Messenger puede crear el contacto aun sin teléfono. La oportunidad es el registro comercial que se agrega al pipeline.
